# ECG 1D-CNN Accelerator | KV260 Engineering Deliverables

**Scope:** Synthesizable streaming ECG classifier, bit-true reference models, design verification, routed FPGA implementation, and KV260 host integration.

| Design item | Released configuration |
| :--- | :--- |
| Device / tool | Kria KV260 (`xck26-sfvc784-2LV-c`) / Vivado 2024.2 |
| Custom IP | `xilinx.com:user:CNN_wrapper:3.0` |
| Datapath | 187 input samples → six Conv1D layers → three FC layers → five logits |
| Numeric format | Q8.8 ; Q2.14; 40-bit Q18.22 accumulator |
| Control / data | AXI4-Lite / AXI4-Stream; PS DDR via AXI DMA |
| Clocking | Single 100 MHz PL clock domain |

## Verification entry points

From the repository root, with Python 3 and Icarus Verilog (`iverilog`, `vvp`):

```bash
python3 04_verification/03_automated_regression/run_regression.py --suite smoke
python3 04_verification/03_automated_regression/run_regression.py --suite core
python3 04_verification/03_automated_regression/verify_weights.py
```

**Release constraints:** Keep `shreg_extract="no"` on `conv1d_parallel_stream.window_buf`; ensure all 52 runtime ROM images are staged; re-check `CNN_wrapper` SRL usage and post-route hold timing after RTL or implementation changes.

**Outstanding:** Automated netlist SRL check, formal/coverage closure, and source-to-Vivado project regeneration are not demonstrated. Some model utilities still contain pre-reorganization import/default paths. The full MIT-BIH CSV, historical RTL, and full Vivado project are not included. This is an engineering demonstrator, not a validated medical diagnostic device.
