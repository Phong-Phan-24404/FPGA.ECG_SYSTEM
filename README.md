# camera_frontend

Independent receive-path RTL for the Sony IMX219:

```text
2-lane MIPI D-PHY parallel bytes
    -> CSI-2 packet decode
    -> RAW10 unpacking
    -> AXI4-Stream, 2 x 10-bit pixels per beat
```

The default `camera_frontend` hierarchy is a dependency-closed extraction of
the full reference-design path:

```text
mipi_csi2_packet_decoder
    -> generated Lattice b2p_inst package
    -> original b2p_axis adapter
```

The complete generated Byte-to-Pixel IP package, metadata, constraints, and
vendor testbench are included. A separately named portable implementation is
also retained for tool-independent smoke testing; it is not the default top.

The project excludes only the serial D-PHY macro (the requested boundary is its
parallel output), sensor I2C setup, downstream debayer/ISP processing, UVC
framing, USB logic, and board implementation.

## Directory layout

- `00_document`: architecture, interface contract, extraction decisions, and
  relevant source-note extracts from `UVC_VS_A`.
- `01_golden_model`: reserved and intentionally empty.
- `02_ reference_model`: reserved and intentionally empty; spelling is retained
  from the requested layout.
- `03_rtl`: extracted receive-path RTL, complete Lattice IP package, and
  explicitly separated portable alternative.
- `04_testbench`: copied vendor Byte-to-Pixel verification and portable smoke
  test.
- `05_fpga_implementation`: reserved and intentionally empty.
- `06_fpga_binaries`: reserved and intentionally empty.
- `07_system_intergration`: reserved and intentionally empty; spelling is
  retained from the requested layout.

Start with `00_document/architecture.md` and
`00_document/interface_specification.md`.

Compile the faithful vendor path:

```powershell
cd .\04_testbench
.\compile_vendor_path.ps1
```

Run the portable functional smoke test:

```powershell
.\run_questa.ps1
```
